# Gebr. de Waard Bestrating website

Statische one-pager. Alles zit in `index.html`.

## Publiceren op GitHub Pages
1. Pak deze zip uit.
2. Maak een repository op GitHub en upload de bestanden (`index.html`, `README.md` en de map `images`).
3. Ga naar Settings > Pages, kies "Deploy from a branch", branch `main` en map `/ (root)`.
4. Na een minuut staat de site op https://GEBRUIKERSNAAM.github.io/REPOSITORY/

## Eigen domeinnaam
Vul bij Settings > Pages > Custom domain uw domein in. Stel daarna bij uw domeinregistrar de DNS-records in zoals GitHub aangeeft.
Let op: laat bestaande mailrecords (MX) ongemoeid, anders valt de e-mail uit.
